# AI Knowledge Assistant

A production-oriented Retrieval-Augmented Generation (RAG) system for querying DAA and Computer Science study material.

## Architecture

- Next.js 14 — frontend
- FastAPI — retrieval service
- ChromaDB — vector store
- BM25 — keyword retrieval
- Sentence Transformers — reranking
- OpenRouter — LLM generation
